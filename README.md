# WallpaperSelector

แอป macOS แบบ native (Menu Bar) ที่สร้างวอลเปเปอร์เดสก์ท็อปให้เปลี่ยนอัตโนมัติตามวันที่/เวลา และสีมงคลประจำวัน (ตามความเชื่อไทยดั้งเดิม)

## สีมงคลประจำวันที่ใช้

| วัน | สี |
|---|---|
| อาทิตย์ | แดง |
| จันทร์ | เหลือง |
| อังคาร | ชมพู |
| พุธ (กลางวัน 06:00-18:00) | เขียว |
| พุธ (กลางคืน 18:00-06:00, ราหู) | เขียวเข้ม |
| พฤหัสบดี | ส้ม |
| ศุกร์ | ฟ้า |
| เสาร์ | ม่วง |

วอลเปเปอร์เป็น gradient ของสีมงคลวันนั้น ปรับความสว่าง/มืดตามช่วงเวลา (เช้า/บ่าย/เย็น/กลางคืน) พร้อมแสดงวันที่และเวลาปัจจุบัน และคาถาบูชาพระประจำวัน (ปางพระ + จำนวนจบที่สวด) บทสวดเต็มดูได้ในเมนูบาร์พร้อมปุ่มคัดลอก

> บทคาถาที่ใส่ไว้เป็นชุดที่เผยแพร่ทั่วไปตามตำราโหราศาสตร์ไทย แนะนำให้ตรวจทานสำเนียงบาลีกับพระ/ตำราวัดอีกครั้งก่อนสวดจริงจัง

## วิธีรัน (แบบ dev)

```bash
swift run -c release
```

## แพ็กเป็นแอป .app (ดับเบิลคลิกเปิดได้)

```bash
./Scripts/build_app.sh
open dist/WallpaperSelector.app
```

สคริปต์จะ build release แล้วประกอบเป็น `dist/WallpaperSelector.app` ให้ ดับเบิลคลิกเปิดได้ปกติ (ไม่ commit ไฟล์แอปเข้า git เพราะเป็น build artifact — รัน `build_app.sh` ใหม่ได้ทุกครั้งที่ต้องการ)

อยากติดตั้งถาวรก็ลากไฟล์ `dist/WallpaperSelector.app` ไปไว้ที่ `/Applications` ได้เลย

แอปจะไปอยู่ที่ Menu Bar (ไอคอนจานสี) ไม่มีไอคอนใน Dock คลิกไอคอนเพื่อ:
- ดูตัวอย่างวอลเปเปอร์ของวันนี้ พร้อมคาถาประจำวัน
- กด "ตั้งเป็นวอลเปเปอร์ตอนนี้" เพื่อ apply ทันที
- เปิด/ปิด "อัปเดตอัตโนมัติ" (เมื่อเปิดไว้ แอปจะสร้างและตั้งวอลเปเปอร์ใหม่ทุกครั้งที่ข้ามชั่วโมง หรือเปลี่ยนวัน)

## เปิดแอปอัตโนมัติตอน login (ทางเลือก)

ลาก `dist/WallpaperSelector.app` (หรือแอปที่ย้ายไปไว้ที่ `/Applications` แล้ว) ไปเพิ่มที่ System Settings > General > Login Items
