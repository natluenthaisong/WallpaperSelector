# WallpaperSelector

แอป macOS แบบ native (Menu Bar) ที่สร้างวอลเปเปอร์เดสก์ท็อปให้เปลี่ยนอัตโนมัติตามวันที่/เวลา และสีมงคลประจำวัน (ตามความเชื่อไทยดั้งเดิม)

## สีมงคลประจำวันที่ใช้

| วัน | สี |
|---|---|
| อาทิตย์ | แดง |
| จันทร์ | เหลือง |
| อังคาร | ชมพู |
| พุธ (กลางวัน 06:00-18:00) | เขียว |
| พุธ (กลางคืน 18:00-06:00, ราหู) | เขียวเข้ม |
| พฤหัสบดี | ส้ม |
| ศุกร์ | ฟ้า |
| เสาร์ | ม่วง |

วอลเปเปอร์เป็น gradient ของสีมงคลวันนั้น ปรับความสว่าง/มืดตามช่วงเวลา (เช้า/บ่าย/เย็น/กลางคืน) พร้อมแสดงวันที่และเวลาปัจจุบัน

## วิธีรัน

```bash
swift run -c release
```

แอปจะไปอยู่ที่ Menu Bar (ไอคอนจานสี) ไม่มีไอคอนใน Dock คลิกไอคอนเพื่อ:
- ดูตัวอย่างวอลเปเปอร์ของวันนี้
- กด "ตั้งเป็นวอลเปเปอร์ตอนนี้" เพื่อ apply ทันที
- เปิด/ปิด "อัปเดตอัตโนมัติ" (เมื่อเปิดไว้ แอปจะสร้างและตั้งวอลเปเปอร์ใหม่ทุกครั้งที่ข้ามชั่วโมง หรือเปลี่ยนวัน)

## เปิดแอปอัตโนมัติตอน login (ทางเลือก)

ไปที่ System Settings > General > Login Items แล้วเพิ่มไบนารีที่ build ไว้ที่ `.build/release/WallpaperSelector`
